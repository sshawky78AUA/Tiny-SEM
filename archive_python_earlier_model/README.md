# Earlier Python model (archive)

These scripts are an earlier version of the Tiny-SEM simulator, kept for reference.
They do **not** reproduce the ICC 2027 paper: they use the earlier parameters
(V = 50, tau = 0.4, R_bh = 250 MB/slot, cache 6%, gamma = 0.02), have no budget margin
theta, and model a single popularity shift instead of the periodic drift of the paper.

Use the MATLAB simulator in `../matlab/` for the results of the paper.
